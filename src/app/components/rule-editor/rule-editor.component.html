Business Rule Expression

How to write complex rules:
  1. Start with your main rule: Produce Error If Contract Identifier in (ABC,DEF)
  2. Leave a blank line, then add section header: Applicability Criteria:
  3. Type numbered conditions: 1. Balance is not null
  4. Press Enter to auto-number next line: 2.
  5. Add more sections: TRIMS Specific Criteria:
  6. Continue with numbered conditions

Important: Section headers must end with "Criteria:" or "criteria:" and be on their own line!
